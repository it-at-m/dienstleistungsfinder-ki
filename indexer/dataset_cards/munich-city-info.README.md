# Munich City Information

This dataset contains public information pages published by the City of Munich. It is generated by the Dienstleistungsfinder-KI indexer from the Magnolia information API.

## Contents

Each row represents one source page. It includes source metadata, the stable `document_id`, and the page's Markdown `content`. The dataset intentionally contains no dense embeddings, sparse vectors, or other vector representations.

## Updates

The indexer replaces the `default` configuration's `train` split after collecting and preparing current source content. The Hugging Face repository and this dataset card are managed separately from the automated export.

## Limitations

The source systems, their availability, and their editorial state determine the dataset contents. The data is informative and is not a substitute for the authoritative information at the linked City of Munich pages.
