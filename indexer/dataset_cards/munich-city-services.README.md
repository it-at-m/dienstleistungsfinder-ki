# Munich City Services

This dataset contains public service articles published by the City of Munich. It is generated by the Dienstleistungsfinder-KI indexer from the municipal service APIs.

## Contents

Each row represents one transformed article. It includes source metadata, the stable `document_id`, and the article's Markdown `content`. Nested category metadata is stored as JSON text. The dataset intentionally contains no dense embeddings, sparse vectors, or other vector representations.

## Updates

The indexer replaces the `default` configuration's `train` split after collecting and transforming current source content. The Hugging Face repository and this dataset card are managed separately from the automated export.

## Limitations

The source systems, their availability, and their editorial state determine the dataset contents. The data is informative and is not a substitute for the authoritative information at the linked City of Munich pages.
